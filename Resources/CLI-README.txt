EPUB Zip CLI 0.1.0 (Apple Silicon)
=================================

这是命令行工具，不是可双击打开的图形应用。

请打开“终端”，进入本目录后运行：

  ./epubzip --help
  ./epubzip pack /path/to/book-folder
  ./epubzip unpack /path/to/book.epub
  ./epubzip check /path/to/book.epub

如果终端提示没有执行权限，请先运行：

  chmod +x ./epubzip

需要图形界面时，请下载并打开 EPUB Zip 的 .dmg 文件。
